# Claude 图标重绘 — 四个方向

所有方案都沿用官方 spark 图形（直接取自 phone-icons 里的路径），只换材质和载体。

## A · 陶釉立体星芒（opt-A）
参照中国银行图标的做法，把扁平星芒做成挤出的立体件，占满整个画布，顶面带光泽渐变，侧面是深赭色的厚度。和官方图标最像，一眼就能认出来，也最符合锤子“把 logo 做成实物”的传统。缺点是星芒很细，没有底板，在图标网格里显得轻、面积小，放在其他方块图标中间会偏弱。

## B · 米纸压印（opt-B）
米白色纸质方块，带很淡的纸纹，星芒像活字印刷一样压进纸里，凹槽上沿有暗边，下沿有受光的亮边。最贴近 Anthropic 暖米色、纸张感的品牌气质，外形和 bilibili 那种圆角方块一致，放进网格里很稳。缺点是比较克制，小尺寸下凹陷的细节会被吃掉，看起来接近“米色底加橙色 logo”。

## C · 火漆印章（opt-C）
赭红色的火漆封蜡，边缘不规则，印章压出一圈凸起的环，星芒凸出在中间，用光照滤镜做出蜡的高光和起伏。物件隐喻最强、最有锤子拟物的趣味，也暗合“信件、认真写字”的意思。缺点是离官方配色和形态最远，识别要靠星芒，而星芒在单色蜡面上对比度低；蜡面带一点噪点质感，是否算“精致”见仁见智。

## D · 聊天气泡（opt-D）
象牙白的光泽气泡，造型参照锤子版微信图标，中间放一个略微凸起的珊瑚色星芒。直接点明“对话式 AI”，暖白配珊瑚色很耐看，小尺寸下星芒对比度最好。缺点是气泡太常见，容易和各种聊天应用混淆，也把 Claude 局限成了“聊天工具”。（另一个没画的备选：深色底上发光的暖色星芒，更“AI”，但和锤子的日常物件风格不太搭。）

## 讨论问题
1. 你更想要“认 logo”（A/D，识别优先），还是“认物件”（B/C，拟物趣味优先）？
2. 要不要底板？A 和 C 是异形轮廓，B 和 D 有完整外形，在你的桌面网格里哪种更协调？
3. 如果选定一个方向，要不要混搭，比如用 B 的米纸材质做成 D 的气泡，或者给 A 加一块陶瓷底座？
