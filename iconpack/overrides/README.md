# 自定义图标

这里的内容会覆盖锤子原图，改完后运行 `node iconpack/scripts/generate.mjs`（或在测试界面点“重新生成”），再运行 `build.ps1` 重新打包。

| 文件 | 作用 |
| --- | --- |
| `icons/<包名>.png` | 新增或替换某个应用的图标，建议 192×192 以上的方形 PNG |
| `icons/<包名>~<名称>.png` | 备选图标：不自动应用，只出现在图标包列表里，用户可在桌面手动换用 |
| `choices.json` | `{"包名": "候选文件名"}`，改用锤子提供的其他候选图 |
| `components.json` | `{"包名": ["启动 Activity 全名"]}`，补充精确匹配，提高 Theme Park 命中率 |
