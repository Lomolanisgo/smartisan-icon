# Microsoft Edge 老 logo（2015 版 "e"）替换方案

- **opt-A 蓝色玻璃方块**：经典 Edge 蓝 (#2F7BD2) 圆角方块，顶部柔和高光与内描边，白色 "e" 带轻微压印阴影。最接近原版老 logo 的观感，也与 bilibili 等方块图标统一。
- **opt-B 立体蓝 e（推荐）**：无底板的满版 3D 蓝色 "e"，带顶部光泽与厚度侧边，如同锤子风格的 Chrome / Firefox 徽标式图标。辨识度最高，最有锤子味道。
  - opt-B-dev：同款造型的绿色版，用于 com.microsoft.emmx.dev 以区分 Dev 通道。
- **opt-C 银白方块蓝 e**：白色/银色渐变圆角方块，中间是带厚度与光泽的蓝色 "e"。清爽明亮，在深色壁纸上更显眼。
